# Local journal notes

Raw notes live in `notes/entries/`. That folder is **gitignored**. The public journal is `content/posts/`. Goals on the site live in `lib/goals.ts`.

## Loop

1. **Pin the goal** on `/goals` (write the description together in `lib/goals.ts`).
2. Copy [TEMPLATE.md](TEMPLATE.md) to `notes/entries/YYYY-MM-DD-short-slug.md`. Set `goal` to the goal slug.
3. Dump bullets while you work. Do not post yet.
4. When the goal is finished, draft the journal together. New posts stay `draft: true` until someone says publish.
5. Mark the goal `done` and link `journalSlug`.

## Do not put in notes

Wi-Fi passwords, API keys, home address, or anything that must never leak if a file is shared by accident.
