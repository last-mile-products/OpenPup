# Build phases

Kid-friendly order of operations. Update this file when a phase finishes; also write a journal post.

## Phase 0 — Story shop (current)

- Name the project OpenPup (puppy name still TBD)
- Stand up this website
- Write Day 0 and the two-brains post

## Phase 1 — Desk puppy

- Boot a Raspberry Pi
- Install OpenClaw
- Speaker + mic on the table (no motors yet)
- First “hello” in the journal with a video

## Phase 2 — Eyes

- Attach the camera
- Prove we can take a snapshot and describe the room
- House-safe privacy rule: we decide where it is allowed to look

## Phase 3 — House brain

- Pick the always-on home computer
- Connect Pi → house over LAN for hard tasks
- Test a question that is too big for the Pi alone

## Phase 4 — Body

- Sketch and 3D-print (or kitbash) a puppy shell
- Wheels first; legs only if wheels feel too boring
- Tail or ear servo for personality

## Phase 5 — House jobs

- Simple chores: announce dinner, find someone, play a sound
- Keep a “things it should never do” list next to the “jobs” list
