This is a little meta, so we'll keep it short.

OpenPup is going to take a while. If we posted every half-finished thought, the site would be a pile of tabs, not a story. If we posted nothing until the puppy could walk, we'd forget how it started.

So we picked a loop.

**1. Pin the goal.** Before we start a chunk of work, we write down what we're attempting and put it on the [goals](/goals) page. Home shows **Now** and **Next**. Visitors can see what we're trying, even if we haven't done it yet.

**2. Do the work without posting.** We talk, we sketch, we break things, we take pictures. Notes stay on our computers. The public site does not get a live blog of every wrench turn.

**3. Finish, then journal.** When that goal is actually done, we write it up here. That's this page, once we flip it from draft to live.

Today's goal was inventing that loop — and putting it on the site so we have to follow it.

Next goal isn't pinned yet. When we pick it, you'll see it under **Next** before we start.
